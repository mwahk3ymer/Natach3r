# Natach3r
# C - argc, argv

This project covers command-line arguments in C.

## Tasks

0. 0-whatsmyname.c - Prints the program name.
1. 1-args.c - Prints the number of arguments.
2. 2-args.c - Prints all arguments.
3. 3-mul.c - Multiplies two numbers.
4. 4-add.c - Adds positive numbers.
5. 100-change.c - Calculates the minimum number of coins for change.

## Compilation

All files are compiled using:

gcc -Wall -Werror -Wextra -pedantic
